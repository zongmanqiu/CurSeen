CurSeen Lua 脚本 API 速查 + 虚拟键盘方案 JSON（供 AI 助手参考，随包分发）
========================================================

## 总体模型
- 脚本 = UTF-8 的 .lua 文件，放进 `assets/lua` 的一个**角色目录**即被扫描（热加载，保存即生效，无需重启）。
- 四个角色目录，归属只看目录：
  - `MouseTrail/` 拖尾特效（role="effect"）：每帧 `step(dt)` + `draw(ctx)`；
  - `HoverDot/` 悬浮标（role="effect" 同款契约）；
  - `ClickFx/` 点击特效（role="effect" 同款契约，还收 `on_press`）；
  - `scripts/` 独立脚本（role 缺省 "composite"）：声明 `menu` 时归入贴图右键「图片操作」，
    否则只在脚本页「运行」；入口 `run(ctx, params)`，返回字符串会自动弹结果框。
- effect 脚本顶层全局：`effect_name`（显示名）、`description`、`schema()`（参数表）、
  `defaults()`（老式默认表，可选）、`init`、`on_move`、`step`、`draw`、`on_press`
  （完整签名与返回值见下文「回调签名与返回值」）。
- composite / scripts 脚本顶层全局：`name`、`description`、`role`、`menu`、`schema()`、`run(ctx, params)`。

## 环境变量（effect 每帧可读）
`screen_w` / `screen_h`（虚拟屏尺寸）、`elapsed`（秒）、`cursor_x` / `cursor_y`（逻辑坐标）、
`mouse_dx` / `mouse_dy`（本帧位移）、`origin_x` / `origin_y`（实例出生点）、`host`（"trail" / "hover" / "clickfx"）、
`wall_ms`（墙钟毫秒）、`_params`（参数表）。

## 全局函数
- `hex_to_rgb("#RRGGBB" 或 "#RRGGBBAA") -> r,g,b,a`（0–255；8 位顺序 R,G,B,A；6 位返回 a=255）
- `rng(min, max) -> float`、`rng_int(min, max) -> int`（整数闭区间；空 / 非法区间安全返回 min）
- `clamp(v, min, max)`、`lerp(a, b, t)`（t 自动钳 0..1）
- `hsv_to_rgb(h, s, v) -> r,g,b`（h 度、s/v 0..1、返回 0..255 整数）
- `play_sound(file, volume?)`：播音效（volume 0..100）。`file` 可为面板 `file` 参数挑的
  路径，或 `assets/Sounds` 里的裸名（如 "click3"）。★ 由宿主注入，仅复合脚本 /
  点击伴生 VM 可用，别的宿主调用它是 "attempt to call a nil value"。

## 绘图 ctx 方法（draw(ctx, params)）
颜色一律 0..255 整数分量；坐标为逻辑坐标（窗口自动处理 DPI / 多屏平移）。
`circle` / `rect` 画**实心**；要描边用 `ring` / `line` / `polygon` 自己拼。
- `ctx:circle(x, y, r, cr, cg, cb, alpha)` —— 实心圆
- `ctx:ring(x, y, r_outer, thickness, cr, cg, cb, alpha)` —— 圆环（描边圈；弧宽≥外径退化成实心）
- `ctx:rect(x, y, w, h, cr, cg, cb, alpha)`
- `ctx:line(x1, y1, x2, y2, thickness, cr, cg, cb, alpha)`
- `ctx:polygon(pts, cr, cg, cb, alpha)`（普通混合）/ `ctx:fill_polygon(pts, cr, cg, cb, alpha)`
  （加色混合）—— pts = `{{x,y},{x,y},...}`（点表，至少 3 点才画）
- `ctx:text(x, y, text, size, cr, cg, cb, alpha)`（左上角锚）/
  `ctx:text_centered(x, y, text, size, cr, cg, cb, alpha)`（中心锚）
- `ctx:layer(name)`：把**后续所有**指令换层；name = `"base"`（垫底先画）/ `"normal"`
  （默认）/ `"top"`（盖顶后画）
- `ctx:clear_circle(x, y, r)`：把圆内像素挖透明（打洞）
- 内置图元：`ctx:glow(x, y, r, cr, cg, cb, alpha)`（辉光）、`ctx:radial(x, y, r, cr, cg, cb, alpha)`
  （径向渐变）、`ctx:diamond(x, y, size, cr, cg, cb, alpha)`、
  `ctx:diamond_rot(x, y, size, angle, cr, cg, cb, alpha)`、`ctx:plus_circle(x, y, r, cr, cg, cb, alpha)`、
  `ctx:image(x, y, scale, alpha)`（宿主注入的悬浮标位图；(x,y)=中心，等比缩放）

## 参数 schema（schema() 返回数组，每项一个字段）
`{ key="", label="", type="", default=…, … }`，type 取值：
`float`（min/max/step）、`int`、`bool`、`color`（#RRGGBB[AA]，可选 `alpha=true`）、
`choice`（`choices={"a","b"}`，可选 `labels={"中文"}`）、`str`（文本输入）、`hotkey`
（组合键录制）、`sound`、`folder`、`file`。★ 没有 `image` 类型：悬浮标图片走
`trail.hover_image` 参数 + `ctx:image()`，别在 schema 里声明图片参数（面板只会有个填了不生效的框）。
用户在卡片里改的参数持久保存在 config.json（`lua_ext.params`），保存即热更新。

## 扩展 API（userdata `ext`，脚本运行期可用）
- `ext:result(text)`：弹可选中复制的文本框（自带消息泵，可在后台线程阻塞）。
- `ext:input(title, default) -> string | nil`：弹输入框；确定=文本，取消/Esc=nil。
- `ext:http(method, url, headers, body) -> { status=int, body=string }`：阻塞 HTTP，
  60 秒超时；错误 status=0。POST/PUT 按 JSON 发。
- `ext:json_encode(value) -> string` / `ext:json_decode(text) -> table | nil`：JSON 互转。
- `ext:log(msg)`：写运行日志。
- `ext:get_image() -> ExtImage | nil`：贴图动作里的当前贴图快照。

## ExtImage 与 ctx.image
只读字段 `.w` / `.h`；方法 `png_base64()`、`bytes()`、`pixel(x,y)`、`save(path)`。
贴图右键触发的 image 脚本在 `run(ctx)` 里拿到 `ctx.image`（同 ExtImage）与 `ctx.hwnd`。

## 文件访问 ctx.fs（相对脚本所在目录，只读）
`ctx.fs:read(path) -> string | nil`、`ctx.fs:read_bytes(path)`、`ctx.fs:exists(path)`、
`ctx.fs:list(path) -> 表`。`../` 与绝对路径一律 nil（越界拒绝）。

## 回调签名与返回值（effect）
- 完整签名（多余的尾部实参可以不接，要用参数就得按序接住）：
  `init()`、`on_move(x, y, t, params)`、`step(dt, t, params)`、
  `on_press(x, y, t, params)`、`draw(ctx, params)`。`t` = 秒；`params` = 参数表
  （同时也写进全局 `_params`）。只写老名 `on_click` 也按 `on_press` 兜底。
- `init()` 的返回值被忽略；**每实例状态直接用脚本自己的全局变量**
  （每个实例一份独立环境，见下方示例）。
- `step` 的返回值当前被忽略：淡出 / 老化自己拿 `t` 对时间戳算，到点把元素从状态表删掉。
- `draw(ctx, params)` 每帧调用，age=0 的帧也会画（出生帧必须画，否则首帧丢特效）；
  返回数字 n>0 = 「n 毫秒后再来一帧」（悬浮标静止时的续帧请求），不返回 = 不要额外帧。

## 复合脚本（scripts/，role 缺省 composite）专属回调
只有 `scripts/` 下的复合脚本收得到这两个（三个特效目录都收不到），是「响应鼠标 / 键盘」的唯一入口：
- `on_mouse_down(button, x, y, params)`：鼠标按下，`button` 取值 `"left" / "right" / "middle" / "x1" / "x2"`。
  ★ 参数顺序与特效的 `on_press(x, y, t)` **刻意不同**，两者不可混抄；此刻的时间读全局 `elapsed`。
- `on_key(key, mods, repeated, params)`：键盘按下。`key` = 键名；
  `mods` = `{ctrl=bool, alt=bool, shift=bool, win=bool}`；`repeated` = 是否长按重复。
  返回值当前不被宿主解释——要发声必须显式调 `play_sound()`。
- 回调容错：除 `schema` / `init` 外，缺失的回调一律静默跳过（不报错、不 panic）。

## 常见坑
- Lua 5.4：没有 `math.atan2`（用 `math.atan(y, x)`）；整除是 `//`。
- 颜色分量必须 0..255（不是 0..1）；alpha 也是 0..255。
- 点击特效实例出生即 active，`on_press(x, y)` 里不要等下一次 move。
- 特效淡出要靠自己在 step/draw 里用 `elapsed` 计算透明度画到 0，并把过期元素从状态表
  里删掉；实例寿命另有宿主兜底，不靠返回值。
- 大文本/长循环会卡渲染帧：脚本每帧预算以毫秒计，别在 draw 里做 IO。

## 完整示例 1：拖尾特效（放进 assets/lua/MouseTrail/ 保存即热加载）
```lua
effect_name = "泡泡拖尾"
description = "鼠标划过时冒出上浮、渐隐的圆圈泡泡"

function schema()
  return {
    { key = "size",  label = "泡泡大小", type = "float", min = 2,   max = 30, step = 1,   default = 10 },
    { key = "fade",  label = "存活秒数", type = "float", min = 0.3, max = 3,  step = 0.1, default = 1.2 },
    { key = "color", label = "颜色",     type = "color", alpha = true, default = "#7FD4FFCC" },
  }
end

bubbles = {}   -- 实例状态用全局变量：每个实例一份独立环境

function init()
  bubbles = {}
end

function on_move(x, y, t, params)   -- 每个鼠标采样点调一次
  bubbles[#bubbles + 1] = { x = x, y = y, born = t,
                            vx = rng(-20, 20), vy = rng(-70, -30), r = rng(0.5, 1.0) }
end

function step(dt, t, params)   -- 老化放 step：鼠标停住也照常消散
  local keep = {}
  for _, b in ipairs(bubbles) do
    if t - b.born < (params.fade or 1.2) then
      b.x, b.y = b.x + b.vx * dt, b.y + b.vy * dt
      keep[#keep + 1] = b
    end
  end
  bubbles = keep
end

function draw(ctx, params)
  local cr, cg, cb, ca = hex_to_rgb(params.color or "#7FD4FFCC")
  local fade = params.fade or 1.2
  for _, b in ipairs(bubbles) do
    local k = 1.0 - (elapsed - b.born) / fade   -- 1 → 0 线性淡出
    if k > 0 then
      ctx:circle(b.x, b.y, (params.size or 10) * b.r,
                 cr, cg, cb, math.floor(ca * k))   -- 实心圆；描边改用 ctx:ring
    end
  end
end
```

## 完整示例 2：复合脚本（放进 assets/lua/scripts/；on_mouse_down / on_key 只有这个目录收得到）
```lua
name = "中键波纹"
description = "中键点击处画一圈外扩渐隐的波纹"

function schema()
  return {
    { key = "color", label = "颜色", type = "color", alpha = true, default = "#FFAA33" },
    { key = "life",  label = "时长", type = "float", min = 0.3, max = 1.5, step = 0.1, default = 0.6 },
  }
end

local rings = {}

function on_mouse_down(button, x, y, params)   -- ★ 参数顺序：先 button 后坐标（与 on_press 不同）
  if button == "middle" then
    rings[#rings + 1] = { x = x, y = y, born = elapsed }   -- 此刻的时间读全局 elapsed
  end
end

function step(dt, t, params)
  local keep = {}
  for _, r in ipairs(rings) do
    if t - r.born < (params.life or 0.6) then keep[#keep + 1] = r end
  end
  rings = keep
end

function draw(ctx, params)
  local cr, cg, cb, ca = hex_to_rgb(params.color or "#FFAA33")
  for _, r in ipairs(rings) do
    local k = (elapsed - r.born) / (params.life or 0.6)   -- 0 → 1
    if k >= 0 and k < 1 then
      ctx:ring(r.x, r.y, 6 + 44 * k, 3 * (1 - k) + 1, cr, cg, cb, math.floor(ca * (1 - k)))
    end
  end
end
```

## 虚拟键盘方案 JSON（assets/VirtualKeyboards/<方案名>.json，丢进去即出现在面板「虚拟键盘」下拉）
一个文件即一套方案，五块都可省略：
- 几何：`"name"` 显示名；`"base_layout": "<内置方案id>"` 引用出厂几何（**纯样式方案**就用
  这个，不带 rows）；`"rows": [ { "keys": [ {...} ] } ]` 自带几何（w 单位 = u = 一个标准键）。
- 每键字段（`rows[].keys[]`）：`code`（三种写法：单字符 `"q"`、枚举名 `"Esc"`/`"LShift"`、
  带编号 `"F5"`/`"Num3"`；空格写 `"Space"`）、`text`（常态图例，省略按 code 派生）、
  `shift_text`（Shift 图例，省略 = text）、`w` / `h` / `pad`、`caps`（字母键写 true，
  CapsLock 开时才变色）、`style`（引用 styles 表）、`radius`（单键圆角）。
- `defaults`（外观默认）：`font_size` / `opacity` / `corner_radius` / `scale` /
  `key_size`（标准键边长 px）/ `gap`（键间空隙 px）/ `hold`（按下高亮保持秒）。
- `styles` 命名样式表（CSS 思路），每项可有：`label` / `fill` / `text` / `border` /
  `press`（**本样式**按下色，双色方案靠它）/ `radius` / `side`（侧壁色 #RRGGBBAA）/
  `depth`（侧壁厚度 px，缺省 3）。立体键帽 = 本体正下方 depth px 垫一颗 side 色键帽、
  底边露出一圈；按下时本体坐进侧壁，即"按压物理感"，无需另设按下位移。
- `state_styles`：`"pressed": { "fill": …, "text": … }` 全局按下态（样式级 press 优先于它）。
- `keys` 逐键覆盖表：键 = 规范化键名（`"CharQ"` / `"SymMinus"` / `"Num1"` / `"Backspace"`…），
  值可有 `text` / `shiftText` / `style` / `radius`。
- `controls`（可选）面板控件清单，每项：`id`（缺省=bind）/ `label`（缺省按 bind 猜中文名）/
  `bind` / `type`（`color` / `range` / `bool`，缺省按 bind 猜）/ `min` / `max` / `step` /
  `decimals` / `default`。`bind` 路径语法：`defaults.fontSize` / `defaults.opacity` /
  `defaults.keySize` / `defaults.gap` / `defaults.hold` / `defaults.cornerRadius` / `defaults.scale` /
  `base.fill|press|border|text`（四个兜底色）/ `pressed.fill|text` /
  `styles.<样式名>.fill|text|border|press|radius|side|depth` / `keys.<键名>.radius`。
  没写 controls 时代码自动补齐预设项 + 每个命名样式的颜色（"看得见改不了"不会发生）。
- 分层优先级（低→高）：内置默认 → defaults → styles → 几何逐键 → keys 覆盖表 → 面板实时调整。
  ★ 鼠标穿透 / 总在最上 / 全屏避让是全局行为，方案干预不了。

## 完整示例 3：虚拟键盘样式方案（放进 assets/VirtualKeyboards/mini_game.json）
```json
{
  "name": "迷你游戏板·蓝",
  "base_layout": "wasd_gaming",
  "defaults": { "font_size": 16, "corner_radius": 6, "opacity": 0.9 },
  "styles": {
    "move": {
      "label": "移动键", "fill": "#2D4A6B", "text": "#E8EEF4",
      "press": "#3A5C85", "side": "#FFFFFF22", "depth": 3
    }
  },
  "keys": {
    "CharW": { "style": "move" },
    "CharA": { "style": "move" },
    "CharS": { "style": "move" },
    "CharD": { "style": "move" }
  },
  "state_styles": { "pressed": { "fill": "#4A6B2D" } },
  "controls": [
    { "label": "移动键颜色", "bind": "styles.move.fill", "type": "color" },
    { "label": "整体不透明度", "bind": "defaults.opacity", "type": "range",
      "min": 0.2, "max": 1, "step": 0.05 }
  ]
}
```
