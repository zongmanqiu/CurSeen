# assets/lua/HoverDot — 悬浮标类型脚本目录

★ 悬浮标架构（2.0）：**每一种悬浮标类型 = 本目录下一个独立的 Lua 脚本**，与 MouseTrail
特效同一套机制——脚本用 `effect_name` 自报显示名、用 `schema()` 自报参数表（宿主据此
自动生成参数面板）、用 `draw(ctx, params)` 每帧绘制。用户选的图片（PNG/GIF）也放在本目录
（配置只记文件名）。

## 脚本每帧能读到的全局变量

| 变量 | 含义 |
|---|---|
| `mouse_x` / `mouse_y` | 指针位置（**物理像素，虚拟桌面坐标**——副屏在主屏左侧时为负） |
| `screen_w` / `screen_h` | 整块虚拟桌面的宽 / 高（物理像素） |
| `elapsed` | 逐帧累加的**动画时钟**（毫秒）。★ 它是每帧 capped 的 dt 累加值，**不出帧就不推进**，只适合做逐帧动画的相位 |
| `wall_ms` | **真实墙钟**毫秒（进程启动至今）。★ 要算"距上次某事件过了多久"（静止检测、超时淡出）必须用它——`elapsed` 在静止期不走动 |
| `_params` | 与 `draw` 的第二个参数同表（兼容老写法） |

辅助函数：`hex_to_rgb("#RRGGBB" / "#RRGGBBAA")`、**`clamp(v, lo, hi)`**、`lerp(a, b, t)`、
`rng(min,max)`、`rng_int(min,max)`。

★ `hex_to_rgb` 返回 **4 个值 `(r, g, b, a)`**：第四个就是颜色自带的透明度
（6 位串恒为 255）。老写法 `local r, g, b = hex_to_rgb(c)` 不受影响。

## 类型 → 脚本 → 参数 对照清单

| 类型 | 脚本文件 | 参数项（schema 顺序） | 绘制说明 |
|---|---|---|---|
| 实心圆 | `solid.lua` | 直径（4–1000）、颜色（**含透明度**） | 内部完全填实的圆盘，`ctx:circle` |
| 圆环 | `ring.lua` | 外径（4–1000）、弧宽（1–999，由外径向内收缩）、颜色（含透明度） | 中心镂空的闭合圆环，`ctx:ring`；渲染层展开为自适应细分的闭合环带多边形，任意外径 360° 闭合无缺角 |
| 图片 | `png.lua` | 缩放（0.1–1，默认 1）、透明度（0–1） | PNG 静态图（任意色型）或 **GIF 动图（逐帧播放）**；文件由面板「图片」行的浏览…导入（复制进本目录，配置只记文件名），**按图片原始宽高 × 缩放**贴出、鼠标落在图片中心 |
| 激光笔 | `laser.lua` | 半径（2–200）、颜色（含透明度） | 指针位置上一个实心圆点，并**全局隐藏系统指针**（脚本声明 `hide_cursor = true`，见下） |
| 聚光灯 | `spotlight.lua` | 光圈半径（10–300，默认 100）、暗罩浓度（0–255） | 整块屏幕压暗、只在指针周围留一个圆形亮圈；整屏 `rect` 走实色快路 + `ctx:clear_circle` 挖洞（Clear 混合），不再逐像素光栅 |
| 屏幕标尺 | `ruler.lua` | 网格间距（50–500，默认 100）、细分刻度（bool）、颜色（含透明度） | 以指针为交点的全屏十字线：双层描边主线（深衬 + 主色，任意壁纸清晰）+ 坐标纸网格（每 grid px 淡线，可数格子测距）+ **三级固定刻度**（主 100px ±11、中 50px ±7、细分 10px ±4，可关）+ 交点圆环。★ 刻度固定且与网格**解耦**：100=2×50=10×10 严格整除 → 相邻刻度恒等距（旧版由 grid/2、grid/5 派生，20 不整除 50 → 忽宽忽窄） |
| 晃动定位 | `locate.lua` | 静止时长（0.2–5 秒，0.2 一档，默认 1.0）、晃动幅度（5–400，默认 40）、显示时长（0.5–5 秒，0.2 一档，默认 3.0）、定位环半径（20–400）、定位环粗细（1–20）、定位环颜色（含透明度） | 平时什么都不画；指针**静止 ≥ 静止时长**后短时间内左右晃动即弹出定位环，环**跟着指针走**，在「显示时长」内线性淡出。★ 不隐藏系统指针、不画中心圆点 |

## `draw` 的返回值 = 续帧请求（淡出动画用）

悬浮标是"静态跟随"特效：指针不动就不出帧（静止 0% CPU）。要在这段时间里跑**自己的**
动画（例如定位环 3 秒淡出），`draw` 返回一个**正数**即可：

```lua
function draw(ctx, params)
  ...
  ctx:ring(x, y, r, w, r8, g8, b8, a)
  return 32      -- 32ms 后再来一帧（≈30fps）
end
```

- 正数 n = "n 毫秒后再来一帧"；不返回 / `nil` / 0 / 负数 = 不要额外帧（立刻收敛回休眠）。
- 老脚本不返回值 → 语义完全不变。
- ★ 没有这条通道，淡出只能靠"指针移动"驱动：手一停，屏上就永久定格在动画的第一帧
  （分层窗帧间不清缓冲），表现为"环不消失"。

## 声明式开关：`hide_cursor`

脚本顶层写 `hide_cursor = true`，宿主就会在该类型启用期间**全局隐藏系统箭头**
（`platform::hide_cursor`：只把 `OCR_NORMAL` 换成全透明位图；I 形/手形/缩放提示保留，2026-10-26 起收窄），失效时自动恢复、
崩溃也另有兜底。激光笔靠它把"真指针"让位给发光的圆点；聚光灯不声明它——那个亮圈里
正需要看到指针本身。

## 图片类型细则（PNG / GIF / 会动的"宠物"）

- **GIF 动图**：把动图文件（如宠物、表情动图）放进本目录并选择即可——宿主逐帧解码、
  按每帧延时循环播放，动画期间自动持续重绘。处置方式（Keep/Background/Previous）
  与 tRNS 透明均正确处理；上限：单帧画布 ≤2048×2048、帧数 ≤120。
- **鼠标跟随"宠物"**：找一个宠物动图 GIF（例如走路的猫）放进本目录并选中，它就会
  跟着鼠标走——这就是最小可用的"鼠标宠物"。需要带状态/交互的正式宠物系统时，
  可在此脚本机制上扩展（脚本每帧都拿到鼠标位置与参数）。
- **PNG 色型**：任意色型均可（RGBA/RGB/调色板/灰度/16-bit，含 tRNS 透明），
  解码失败会在 `build/log/` 写明原因。
- ★ **宽高比（2026-09-22 改）**：图片**不再被裁成正方形**——PNG 与 GIF 都按文件的原始
  宽高交给绘制端，脚本只给一个「缩放」倍数（0.1–1，默认 1 = 原始尺寸），宿主按
  `原始宽 × scale` / `原始高 × scale` 铺开并把鼠标对准图片中心。`ctx:image(x, y, scale, a)`
  的第三个参数就是它（早先是边长，非方图会被拉变形）。

## 如何新增一个悬浮标类型

1. 在本目录新建 `<id>.lua`（id 即文件名 stem，全小写无空格）；
2. 写 `effect_name`（下拉显示名）、`schema()`（参数表：key/label/type/min/max/step/default）、
   `draw(ctx, params)`（用 `ctx:circle / ctx:ring / ctx:image / ctx:line / ctx:radial / ctx:polygon ...` 画）；
3. 重新打开控制面板——类型下拉会自动出现新类型（目录每次开面板都重扫）。

可用参数类型：`int`（整数滑块）、`float`（小数滑块）、`bool`（开关）、`color`（颜色选择器）、
`choice`（下拉）。

### 颜色的透明度：`alpha = true`

颜色参数默认**不带透明度**（恒 6 位 `#RRGGBB`）——这类脚本要么另有一条「不透明度」
参数，要么本来就不该半透明。要让取色器长出透明度条，在 schema 里显式声明：

```lua
{ key = "color", label = "颜色", type = "color", alpha = true, default = "#00E5CC" },
```

- 声明后落盘是 8 位 `#RRGGBBAA`（**alpha 在末尾**，与 `Argb::parse_hex` 同口径），
  `local r, g, b, a = hex_to_rgb(params.color)` 拿到 alpha（0–255）。
  （别写成 `#AARRGGBB`，否则 `default = "#FF000040"` 会被读成不透明深蓝。）
- ★ **两种透明度不许并存**：脚本要么用颜色里的 alpha，要么用独立的「不透明度」参数。
  两套并存会互相打架（同一个视觉量有两个来源，改哪个都"好像没生效"）。本目录五个
  形状类脚本（实心圆 / 圆环 / 激光笔 / 屏幕标尺 / 晃动定位）**统一走颜色 alpha**，
  没有独立的「不透明度」参数。

★ **秒类参数用 `float` + `step`**：schema 里写 `{ type = "float", min = 0.2, max = 5.0,
step = 0.2, default = 1.0 }`，面板会把它渲染成**按 0.2 吸附**的小数滑块（显示 1 位小数），
拖到两档之间松手会自动归到最近那一档——读数与落盘值同源。`step` 同时决定显示小数位
（≥1 → 0 位、≥0.1 → 1 位、≥0.01 → 2 位）。

★ **要在同一帧里挖洞（画"带孔的实心区域"）时**：填充走的是非零环绕规则
（`tiny_skia::FillRule::Winding`），因此**内外两圈的绕向必须相反**，同向会把洞填实。
环带多边形的标准画法是「外圈角度 0→2π 正向 + 内圈 2π→0 反向」，两个圈的首末点都落在
角度 0 上，自动闭合的接缝正好是二者的公共径向边（`spotlight.lua` 与渲染层的
`circle_annulus_polygon` 都是这个形状）。

## 注意

- 本目录的 `.lua` 会被面板扫描成悬浮标类型；用户 PNG/GIF 图片也放这里，互不冲突。
- 删除某个 `.lua` 即移除该类型（配置里残留的类型 id 会被回退到第一项）。
- 全局功能总开关已废除：悬浮标卡片的开关就是它的唯一开关。
