# 屏幕与捕获（标注 / 放大 / 截图贴图 / GIF / 录屏）

「屏幕」页的判据是**操作对象是不是屏幕画面**：画它（标注）、放大它（画中画 / 全屏放大）、
抓一帧（截图）、抓多帧（GIF）、抓一段（视频）。配置键的完整表在
[`配置说明.md`](配置说明.md)。

## 1. 这个主题管什么

| 功能 | 产物 | 关键入口 |
|---|---|---|
| 屏幕标注 | 一张带标注的 PNG（`temp/annotation/`） | 父卡开关 + 13 个书写快捷键 |
| 画中画放大 | 屏幕上的一块放大镜窗 | 开关 + 启停快捷键 |
| 全屏放大 | 整屏放大，Esc 退出 | 开关 + 启停快捷键 |
| 截图与贴图 | 剪贴板 + `temp/screenshot/` 留档；贴图钉在桌面 | 截图 / 截图后贴图 / 贴图 / 长截图四把键 |
| GIF 录制 | 一个 `.gif`（`temp/gif/`） | 录制一键开关 + 裁剪键 |
| 视频录制 | 一个 `.mp4`（`temp/record/`） | 录制一键开关（可与区域/裁剪键配合） |

出厂**所有快捷键留空**：空串 = 停用且看得见，不预占用户的全局键位。各功能卡标题栏的
开关只关"这个功能的快捷键与动作"，不会删产物。

## 2. 屏幕标注

- 父卡「屏幕标注」的开关是唯一开关；下面两张子卡：「画笔」三类笔（颜色 / 粗细 / 线型）
  与「快捷键」13 把。
- 快捷键顺序 = 工具栏按钮序：屏幕标注、白板、画笔 1/2/3、直线、箭头、矩形、椭圆、文字、
  图章、马赛克、橡皮擦、序号。
- 标注产物统一落 `temp/annotation/`（不落 exe 同级的独立文件夹）。
- 「白板」= 在空白画布上写，不截桌面。

## 3. 画中画与全屏放大

- 画中画（`magnifier_pip.*`）：面板宽高、倍率、锚点（含"跟随鼠标"）、偏移、描边颜色、
  启停快捷键。运行中的 `active` 是瞬时态，不落盘。
- 全屏放大（`magnifier_fullscreen.*`）：倍率 1–5，快捷键留空时只能从面板开关启动；
  **Esc 永远能退出**，不依赖快捷键字段。
- 两者都在覆盖层的置顶策略下：设置页「总在最上 / 全屏避让」对所有屏幕工具一起生效。

## 4. 截图与贴图

- 四把键：截图（区域 → 剪贴板 + 留档）、截图后贴图（区域 → 剪贴板 + 钉到桌面）、
  贴图（从剪贴板历史取图文钉到桌面）、长截图（开始 / 结束一键开关）。
- 贴图数量上限 `screenshot.pin_ring_cap`。贴图窗右键可另存为、旋转、镜像、恢复原图。
- 截图默认不弹保存对话框：要留的文件用贴图右键「另存为」；临时留档在 `temp/screenshot/`。
- 「贴图」的素材来源是**剪贴板历史**（文本会栅格化成位图，文件条目跳过）；剪贴板模块
  关着时退回当前剪贴板。多次按贴图键 = 沿历史往前翻。

## 5. GIF 与视频录制

- GIF：一键开关开始 / 停止；选框即输出尺寸；循环恒定开启；`fps` 与「录制鼠标」可调；
  裁剪窗有独立快捷键。产物 `temp/gif/`。
- 视频：一键开关（录制中再按 = 停掉当前这段）；画面（帧率 / 分辨率 / 码率 / 硬件加速 /
  录制鼠标）与声音（系统声音 / 麦克风 / 降噪）分两张子卡。产物 `temp/record/`。
- 音频两路各一行三态下拉（关闭 / 默认 / 指定设备）；麦克风降噪出厂「中」；试听按钮
  恒显示，来源为「关闭」时会先把来源切到「跟随系统默认」再试听。
- **没有暂停**：录制是一条流式通道，暂停语义只会制造半截文件；要分段就停掉再开。

## 6. 产物与清理

- 程序自己产生、用户没有指定位置的产物统一在 `<程序目录>/temp/<模块>/`：
  `screenshot` / `annotation` / `gif` / `record` / `clipboard`。
- 启动时按 `general.temp_cleanup_days` 清理工作文件夹（永不 / 7 / 30 / 180 天）。
  用户要留下的东西走各自的「另存为」，不要指望工作文件夹长期保存。
- 目录建不出来时退回 `temp/` 根，再不行退回程序目录——产物位置是尽力而为，功能不因
  目录问题失败。

## 7. AI 的任务路线

这些功能**没有 Lua 脚本接口**（不要编造 `draw` 回调去驱动它们）。AI 能做的是：

1. **改快捷键 / 参数**：告诉用户面板路径，或（有文件权限、程序已退出时）改
   `config.json` 里对应的键，见《配置说明》。MCP 工具不写这些键。
2. **找产物**：按上表去 `temp/<模块>/` 找；找不到先看该功能是否真的启用、快捷键是否为空。
3. **排错**：录制没声音先查两路音频来源；GIF 与视频的产物在不同目录，别互相找错。

## 8. 边界与常见错

| 症状 | 先查 |
|---|---|
| 按快捷键没反应 | 功能卡开关是否关着；快捷键是否为空；是否被别的软件占用 |
| 录出来没声音 | 系统声音 / 麦克风两路是否「关闭」；指定设备是否还在 |
| 找不到截图文件 | 截图默认只进剪贴板 + `temp/screenshot` 留档，没有"保存目录"设置 |
| 贴图总是同一张 | 「贴图」取的是剪贴板历史；刚复制过什么会决定顺序 |
| 全屏放大退不出来 | Esc 不受快捷键留空影响，任何情况下都能退 |
| 工作文件夹被清空 | `general.temp_cleanup_days` 的自动清理；重要产物要另存 |
