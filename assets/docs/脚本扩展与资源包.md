# 脚本扩展与资源包（role / ext / pack.json）

这份文档讲**脚本能做什么、放在哪、怎么打包分发**。语法与逐条签名不在这里：
结构看 [`Lua开发指南.md`](Lua开发指南.md)，接口看 `../lua/API.md`。

## 1. 四类角色由挂载目录决定

| 目录 | 缺省 `role` | 宿主 | 模型 | 出现在哪 |
|---|---|---|---|---|
| `assets/lua/MouseTrail/` | `effect` | `trail` | 逐帧回调 | 鼠标页「拖尾」下拉 |
| `assets/lua/HoverDot/` | `effect` | `hover` | 逐帧回调 | 鼠标页「悬浮标」下拉 |
| `assets/lua/ClickFx/` | `effect` | `clickfx` | 逐帧回调 | 鼠标页「点击效果」按鼠标键分开选 |
| `assets/lua/KeySound/` | `keysound` | — | `run(ctx, params)` | 键盘页「击键音效」下拉 |
| `assets/lua/scripts/` | 无 `menu` → `composite`；有 `menu` → `image` | `panel` / — | 逐帧回调 / `run` | 脚本页卡片；`image` 另进贴图右键「脚本」 |

- **五个挂载都热重载**：脚本文件改完立刻生效；`KeySound/` 在下一次按键生效。
- `role` 可以显式写；缺省由目录与 `menu` 推演。落在其它目录的散件会告警并跳过。
- 脚本 id = 相对 `assets/lua/` 的路径去扩展名（`scripts/包名/foo`）；在线包安装后
  整个文件夹替换，**id 不变**，用户的参数 / 快捷键 / 启用状态都能对上。

## 2. 一个脚本由什么组成

| 部分 | 写法 | 说明 |
|---|---|---|
| 显示名 | 顶层 `name` / `effect_name` | 下拉与卡片上看到的文字；缺省用文件名 |
| 说明 | `description` | 一句话；卡片副标题 |
| 菜单文字 | `menu` | 有它 = `image` 角色，进贴图右键「脚本」 |
| 参数表 | `schema()` 返回数组 | 面板据此生成控件；参数只在 `schema()` 里声明 |
| 依赖 | `requires = {"tool/x.exe"}` | 缺任一文件 ⇒ 不进贴图右键菜单（缺省可见） |
| 隐藏指针 | `hide_cursor = true` | 只隐藏箭头，I 形 / 手形保留 |
| 回调 | `draw` / `step` / `on_move` / `on_press` / `on_click` / `on_mouse_up` / `on_wheel` / `init` | 不同宿主转发不同集合，见 API §8 / §10 |
| 入口 | `run(ctx, params)` | 仅 `image` / `keysound`；跑在工作线程 |

参数口径两条硬规矩：

1. **`schema()` 的 `default` 不会自动进 `params`**（只有 `image` 的 `run` 会合并）。
   脚本里 `params.x or 默认值` 的兜底必须与 schema 一致，否则离屏与真机行为不同。
2. 声明了但没在脚本里读的参数，`lua_check` 会报 warning；面板上拖它不会有任何效果。

## 3. 扩展能力 `ext`（所有脚本可用）

| 类别 | 成员 | 注意 |
|---|---|---|
| 进程 | `proc` | 只准起**脚本自己目录**里的 `.exe`；阻塞，仅 `run` 模型 |
| 网络 | `http` / `download` | 阻塞，仅 `run`；`download` 流式写盘、上限 512 MB |
| 压缩 | `unzip` | 拒绝 `..` / 绝对路径 / 符号链接条目；不支持的格式明确报错 |
| 对话框 | `input` / `open_file` / `save_file` | `open_file` 由用户选，可以是任意绝对路径 |
| 文本窗 | `result` | 显示结果并允许复制；阻塞在脚本线程 |
| AI 窗 | `chat_window` | 原生多轮对话窗；历史存 `data/ai_chat/history.json`，不存 Key |
| 图片 | `get_image` / `load_image` / `set_image` / `ExtImage` | 裁剪 / 旋转 / 镜像 / 保存；没有任意缩放 |
| 剪贴板 | `clip_get` / `clip_image` / `clip_set` | `clip_set` 写完立刻读回核对 |
| 文件 | `read_file` / `write_file` / `tmpdir` / `data_dir` / `script_dir` | 任意路径；`write_file` 写后回读核长度 |
| JSON | `json_encode` / `json_decode` | 连续整数键的表 = 数组 |

- **阻塞类只能在 `run` 模型里调**：`http` / `proc` / `download` / `input` / `chat_window`。
  逐帧回调跑在 UI 线程，在那里阻塞会冻住整个界面（工具会拒绝）。
- 落点三分：临时 `ext:tmpdir()`；持久状态 `ext:data_dir()`（`data/lua/<id>/`）；
  **用户可见设置只写 `config.json`**，别拿 data_dir 代替设置。
- `ctx.fs` 是另一个东西：只读、根 = 脚本目录，仅 `run` 模型可用；越界读返回 `nil`。
- 信任模型一句话：**装脚本 = 交出这个账号的权限**，没有沙箱。`ext` 的路径收口
  防的是手滑与误装，不是恶意脚本。

## 4. 资源包（在线安装的形状）

官方包在 `CurSeen-Scripts` 仓库的 `Packs/<id>/`，一个子目录一个包：

```text
Packs/<id>/
├─ pack.json          包配置：id / 版本 / 分类 / 效果清单 / 默认项
├─ scripts/           该包的 .lua；同目录资料（如 API 说明）也放这里
└─ info/              必须三件：LICENSE、README.md、HISTORY.md
```

- 安装后落在 `assets/lua/scripts/<id>/`；`pack.json.id`、目录名、`scripts.json` 的 id
  三者必须一致。
- 每包必须有 `info/LICENSE`、`info/README.md`、`info/HISTORY.md`，缺手续的包宿主拒收。
  `HISTORY.md` 只增不改，每次发版在最上面加一段版本记录。
- 发布 zip 里的 `pack.json` 由打包脚本生成：保留源字段，再补 `layout: 2` 与全量
  `files` 清单。源码目录的 `pack.json` 与发布用的不是一回事。
- 单脚本包写 `"single": true`（脚本页出一张普通卡，不摆"一项的下拉"）；
  `category`（`mouse` / `picture` / `text` / `ai`）只影响脚本页排序，不改 id。
- 官方包现役：鼠标特效四包（CursorFX / CursorX / MFCMouseEffect / MouseEffects）、
  AI 写脚本、图片体检、OCR、条码。
  用户在脚本页第一张卡（资源下载）安装 / 升级 / 卸载；下载源在设置页「高级」。

## 5. AI 的任务路线

- **写一个新脚本**：`list_scripts` → 读 [`Lua开发指南.md`](Lua开发指南.md) + 目标主题文档
  → `write_script` → `lua_check` → `lua_trace` → `set_active`。
- **小改一处**：`patch_script`（`old_text` 必须唯一命中，整批原子）→ `lua_check`。
- **打包发布**：没有 MCP 通道。按 `CurSeen-Scripts` 仓库《开发指南》组织 `Packs/<id>/`，
  跑打包脚本生成 zip 与 `scripts.json`。
- **安装别人的包**：让用户在脚本页的资源卡里装；安装 / 升级会替换整个包文件夹，
  不要手工往包目录里塞文件（升级会丢）。

## 6. 边界与常见错

| 症状 | 先查 |
|---|---|
| 脚本页没有卡片 | 目录不对；`role` / `requires` 不满足；或包缺 `info/` 手续 |
| 贴图右键里没有「脚本」项 | 没有 `menu`，或 `requires` 的文件缺了 |
| 参数拖了没反应 | 脚本里没读该参数；或 schema default 与兜底值不一致 |
| 改了脚本没生效 | 五个挂载都热重载；`KeySound/` 在下一次按键生效。仍没变化就查 `host_status` |
| `ext:proc` 报路径不合法 | exe 必须在脚本自己目录（含子目录）里，且是 `.exe` |
| `ext:http` 返回 status=0 | 在 `draw` 里调用了阻塞 API；挪进 `run` |
| 升级后自己的改动没了 | 包升级是整文件夹替换；改动要以新版本发布 |
