# 虚拟键盘（击键回显 / 击键音效 / 键帽 / 直播捕获）

键盘页上的三张卡其实是三件不同的事：**击键回显**（打出你按的键）、**击键音效**
（按键发声）、**虚拟键盘**（把整套键帽画在屏幕上）。直播捕获挂在虚拟键盘卡里，
把这块键盘变成直播软件能抓的来源。配置键的完整表在 [`配置说明.md`](配置说明.md)。

## 1. 这个主题管什么

| 卡 | 产物 | 数据来源 |
|---|---|---|
| 击键回显 | 屏幕角落的一个弹窗，显示刚按下的键 | 全局键盘钩子 + `assets/KeyDisplay/keynames.ini` 键名表 |
| 击键音效 | 按键时播放一段音频 | `assets/lua/KeySound/` 下的脚本（`run(ctx, params)` 模型） |
| 虚拟键盘 | 一块常驻的键盘画面 | `assets/VirtualKeyboards/*.json` 方案 + 面板参数 |
| 直播捕获 | 直播软件里的一个画面来源 | 上面那块键盘的第二种呈现表面 |

## 2. 击键回显

- 模式（标题栏下拉）：`all` 全部 / `no_mouse` 排除鼠标 / `shortcuts_fun` 组合键 + 功能键 /
  `shortcuts` 只看组合键。配置键 `key_display.display_mode`。
- 位置：四个角落（`key_display.placement`：`top_left` / `top_right` / `bottom_left` /
  `bottom_right`）+ 四向偏移。显示：宽度、不透明度、停留时长、字号、合并间隔。
- 颜色：背景、普通键、功能键、符号键四个色块（固定四色，与"方案"无关）。
- **键名文字**改 `assets/KeyDisplay/keynames.ini`：文件保存后按下一次键即生效，无需重启；
  格式与键名 ID 清单在文件头注释里。缺失的键回退内置默认名。
- 这些都不需要写脚本；MCP 也没有改 `keynames.ini` 的通道。

## 3. 击键音效

- 下拉选的是 `assets/lua/KeySound/` 里脚本的文件名 stem（如 `KeySound/unified_sound`），
  配置键 `key_sound.script`；音量 `key_sound.volume`；脚本声明的参数走 `key_sound.params`。
- 脚本契约：`run(ctx, params)`，**按键触发一次**，不是逐帧绘制。能读 `ctx.key`、
  `ctx.mods`、`ctx.repeated`、`ctx.sounds`。返回值的语义（静音 / 指定文件 / 指定候选序号）
  见 `../lua/API.md` §11。
- 音效文件可以在面板里浏览选择；`assets/Sounds/` 是点击声音、键盘声音、拖尾音效共用的
  出厂音源目录，丢一个音频文件进去就能在下拉里选到。
- 新写键音脚本：`write_script` 到 `KeySound/<名字>.lua` → `lua_check`。`lua_trace`
  **不支持**键音脚本（它的契约不是逐帧），工具会明确报错而不是给假 fail。

## 4. 虚拟键盘方案（`assets/VirtualKeyboards/*.json`）

**一个文件一套方案，文件名即方案 id**，面板下拉直接扫这个目录。方案可以省到只有
`baseLayout` 继承一套出厂几何，再覆盖样式；完整的四块结构：

| 块 | 作用 | 省略时 |
|---|---|---|
| `rows` | 几何：行数组 + 每键 `code` / `text` / `shiftText` / `w` / `h` / `pad` | 用 `baseLayout` 指向的几何 |
| `defaults` | 外观默认：字号 / 圆角 / 缩放 / 总不透明度 / 键帽大小 / 空隙 / 高亮保持 | 内置默认 |
| `styles` + `stateStyles` | 命名样式（填充 / 文字 / 描边 / 按下色 / 圆角 / 立体边） | 面板四个兜底色 |
| `keys` | 逐键覆盖（文字 / 上档文字 / 样式 / 圆角） | 几何里写的那份 |
| `controls` | 面板控件清单（暴露哪些项、叫什么、范围多大） | 代码自动补齐预设 |

- 几何文件名约定是 `几何前缀_样式`（`ansi_104` / `ansi_104_dark` / `ansi_60` …）；
  换方案时面板会按方案重建参数区。
- 鼠标穿透、总在最上、全屏避让是**全局行为**，方案不能预设；位置与四向偏移同样在
  面板上（`virtual_keyboard.placement` + 偏移，偏移单位是百分比）。
- 面板实时调整优先于方案默认值；方案作者改 `defaults` 只影响"面板值仍等于出厂默认"的项。
- 改完方案 JSON 后，回面板重新选一次该方案（或重启程序）最稳妥。

## 5. 直播捕获（`live.*`）

三个可选来源，**默认「桌面」**（不建窗、不起服务）：

| 来源 | 做法 | 边界 |
|---|---|---|
| 桌面 | 键盘画在覆盖层上，用直播软件的「显示器捕获」 | 不需要任何额外配置 |
| 独立窗口 | 额外开一扇 `CurSeen 虚拟键盘` 窗口，用「窗口捕获」 | 窗口可拖、可关、可最小化；最小化时平台规则下抓不到 |
| 浏览器源 | 本机 HTTP 服务（默认 `127.0.0.1:8765`），用 OBS 家族的「浏览器」来源 | 只适用于 OBS / 直播姬 / Streamlabs 这类 |

- 窗口与浏览器源的尺寸都**跟键盘实际包围盒走**；独立窗口还有「窗口缩放」（0.5–3×），
  内容按同一倍数**重新矢量渲染**，不是把位图拉大——拉大来源只会更糊。
- 浏览器源地址必须带完整 `http://`。直播姬在来源没写协议时会自动补 `https`，导致
  源空白；用面板上的「复制地址」把完整地址粘过去。
- 「来源尺寸」显示的是浏览器源当前输出的像素尺寸；在直播软件里把来源宽高设成这个值
  就能避免黑边。端口被占时会自动顺延，复制的是实际在用的地址。
- 抠图底色是**色键**：底色与键帽撞色会被一起抠穿，撞了就换一色。窗口模式下 DWM 圆角
  会啃掉键帽直角，程序已显式关掉圆角。
- 关掉那扇窗 = 取消「独立窗口」选择；这是同步的，不会自动弹回来。

## 6. AI 的任务路线

- **写键音脚本**：`write_script` → `lua_check`（不要跑 `lua_trace`）→ 用面板或
  `key_sound.script` 启用。
- **改键名显示**：没有 MCP 通道，告诉用户改 `assets/KeyDisplay/keynames.ini`。
- **新增键盘方案**：没有 MCP 通道，写 `assets/VirtualKeyboards/<id>.json`（有文件权限时），
  或让用户在面板里复制一份再改。
- **配置直播**：`live.mode` / `live.window_scale` / `live.bg` / `live.browser_port` 都在
  `config.json`，MCP 工具不写这些键；运行中改文件会被内存配置覆盖，先退出程序再改。
- **写虚拟键盘的自动判据**：`lua_trace` 只驱动四类特效/复合脚本，**没有键盘宿主的离屏判据**；
  真要验画面，只能真机截图。

## 7. 边界与常见错

| 症状 | 先查 |
|---|---|
| 键音脚本下拉里没有 | 文件不在 `assets/lua/KeySound/`，或文件名不是 id |
| 浏览器源全空 | 地址是不是 `https://…`；粘「复制地址」给出的完整 `http://` 地址 |
| 直播画面糊 | 别在直播软件里拉大来源；用窗口缩放或提高浏览器源尺寸 |
| 直播里键盘缺角 | 色键底色与键帽撞色；换底色 |
| 独立窗口抓不到 | 窗口被最小化了；平台规则下最小化窗不可捕获 |
| 改了方案没生效 | 回面板重新选一次方案或重启程序 |
| 键名改了没变 | `keynames.ini` 保存后要再按一次键 |
