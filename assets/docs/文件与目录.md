# 文件与目录（程序版图与读写边界）

CurSeen 是**便携程序**：解压即用，配置、日志、缓存、临时产物都留在程序目录，
不写 `%APPDATA%`。卸载 = 删除整个目录。这份文档回答"什么东西放在哪、谁可以写、
AI 动哪些文件是安全的"。

## 1. 根目录版图

```text
<程序目录>/
├─ curseen.exe            主程序（同一个 exe 也是 --mcp / --lua-check 的工具台）
├─ config.json            用户配置；首次保存时生成；程序运行期间以内存版为准
├─ assets/                随包资源（见下一节），运行时不写
├─ licenses/              第三方许可证（随包，别改）
├─ log/                   日志；排错先看这里
├─ update/                更新中转（下载的 zip 与替换脚本，完成即清理）
├─ data/                  程序/脚本的持久数据（按需创建）
│  ├─ lua/<脚本 id>/      脚本私有数据（ext:data_dir()）
│  └─ ai_chat/history.json  AI 对话窗的历史（不含 API Key）
└─ temp/                  运行期产物，按模块分子目录（见 §3）
```

- **配置文件只有一处**：`<程序目录>/config.json`。从哪个工作目录启动都读它；
  别去找 `%APPDATA%` 或注册表。
- 程序运行时会用自己的内存配置，**手改 `config.json` 前先退出程序**，否则可能被覆盖。
- 普通权限即可运行；「设置 → 高级 → 管理员启动」是可选项，不是必需。

## 2. assets 目录（只读）

`assets/` 下**一个功能一个文件夹**：`lua/`（脚本根）、`Sounds/`（共用音源）、
`VirtualKeyboards/`（键盘方案）、`KeyDisplay/`（键名表）、`icons/`、`images/`、
`docs/`（本目录）、`cache/`（联网清单缓存）。完整版图见 `../README.md`。

- 运行时不写 `assets/`：用户选的悬浮标图片是唯一例外（那是显式"导入素材"）。
- `assets/cache/` 是**例外**：`scripts.json` / `update.json` 由程序联网刷新时替换，
  不要手改，也不要当成用户数据。
- `assets/docs/` 只读：程序不覆盖它，你改的内容会保留，但升级换包时可能被新版覆盖。

## 3. temp 目录（运行期产物）

| 子目录 | 内容 |
|---|---|
| `temp/screenshot/` | 截图留档（截图本身默认进剪贴板） |
| `temp/annotation/` | 屏幕标注导出的 PNG |
| `temp/gif/` | GIF 产物 + 裁剪窗默认打开目录 |
| `temp/record/` | MP4 录屏产物 |
| `temp/clipboard/` | 剪贴板历史 `history.jsonl`、图片原件与缩略图 |
| `temp/lua_shot/` | `lua_shot` 离屏出图 |
| `temp/lua_tool_trash/` | `delete_script` / `patch_script` 的备份（不真删） |
| `temp/lua_tool_state.json` | 宿主状态快照（pid / 重扫时间 / 面板状态），`host_status` 读它 |

- 启动时按 `general.temp_cleanup_days`（永不 / 7 / 30 / 180 天）清理工作文件夹。
  要长期保存的产物走各功能的「另存为」，别指望 temp 长期保留。
- 目录建不出来时退回 `temp/` 根，再不行退回程序目录；功能不会因目录问题失败。

## 4. 读写边界（AI 必须遵守）

| 通道 | 能写什么 | 不能写什么 |
|---|---|---|
| MCP `write_script` / `patch_script` / `delete_script` | `assets/lua/` 五个挂载目录（`MouseTrail` / `HoverDot` / `ClickFx` / `KeySound` / `scripts`） | 其它目录、`..`、目录外绝对路径 |
| MCP `set_active` | `config.json` 里对应挂载点的键 | 其它配置键（工具只改它认识的那几个） |
| 有文件权限的 agent | 同上，另可按《配置说明》改 `config.json` | 运行中改配置；改 `assets/cache/` |
| Lua `ext:*` | 任意路径（`read_file` / `write_file` / `download` / `unzip`） | ——（见信任模型） |
| Lua `ctx.fs` | 只读，根 = 脚本目录 | 任何写入；越界读 |

- **路径纪律**：命令行与 MCP 工具的参数一律写**相对程序目录**的路径；写入只接受
  `assets/lua/` 五个挂载目录。绝对路径只接受落在程序目录内的。
- **Lua 的 `ext` 不是沙箱**：`ext:write_file` / `download` / `unzip` / `proc` 的收口
  （`proc` 只准起脚本自己目录里的 `.exe`）是防手滑与可审计，不是安全边界。装脚本 =
  交出这个账号的权限，与装任何来源的 exe 同级。
- **脚本落点三分**：临时文件 `ext:tmpdir()`；持久状态 `ext:data_dir()`
  （`data/lua/<id>/`，不被 temp 清理）；用户可见设置只写 `config.json`。

## 5. AI 的常见任务

- **找产物**：先按 §3 的模块目录找；找不到再看功能开关与快捷键。
- **清缓存/排错**：`log/` 是日志；`assets/cache/` 可以删（程序会重新联网取），但别改内容。
- **别碰**：`licenses/`、`assets/icons|images`（生成产物）、`assets/docs/`（只读）、
  用户 `data/lua/` 里不属于本次任务的脚本数据。

## 6. 边界与常见错

| 症状 | 先查 |
|---|---|
| 改了 `config.json` 没生效 | 程序还开着，内存配置把它覆盖回去了 |
| 工具说"路径必须落在程序目录内" | 用了绝对路径或 `..`；改成相对写法 |
| 升级后配置还在吗 | 在：配置在程序目录根部，升级只换 exe 与 assets |
| 卸载残留 | 便携程序不自写注册表/AppData；删目录即卸载（用户自己放到别处的产物除外） |
| 日志太大 | `log/` 可清理；别删 `assets/cache/` 之外的随包文件 |
