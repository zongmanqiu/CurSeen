# 工具与小部件（便签 / 剪贴板 / 计时器）

「工具」页放的是**不对应任何硬件**的三件小工具：便签操作的是你的文字、剪贴板操作的是
复制的内容、计时器操作的是时间。它们没有 Lua 接口，AI 能改的是配置与快捷键。
键表在 [`配置说明.md`](配置说明.md)。

## 1. 便签（`sticky_note.*`）

- 快捷键呼出**一张新便签**；可以同时开多张。每张都是原生顶层窗：可拖动、可置顶锁定、
  可收起编辑区。
- 可调：背景色 / 文字色 / 编辑区色、不透明度、字号（`sticky_note.enabled` 是功能开关）。
- ★ **便签内容不持久化**：它不写 `config.json`，也不落盘；关掉窗或重启程序就没了。
  要长期保存的文字请用别的工具——不要把这里当笔记本。
- 这个功能没有脚本接口，也没有 MCP 写通道。

## 2. 剪贴板历史（`clipboard.*`）

- 后台监听复制，面板里可按类型过滤、搜索、收藏、悬停预览、点击粘贴。
- 条目类型优先级：**文件（CF_HDROP）> 图片 > 文本**。图片会落盘成 PNG
  （`temp/clipboard/images/` 原件、缩略图在 `temp/clipboard/thumbs/`），历史本身写在
  `temp/clipboard/history.jsonl`，**重启后仍在**。
- 配置：`clipboard.enabled`、`clipboard.hotkey`（呼出面板）、`clipboard.max_entries`
  （历史条数上限）、`clipboard.panel`（面板位置与固定状态，程序自己记）。
- 捕获到裸图时会当场把剪贴板重写成"文件引用 + 像素"，这样资源管理器与聊天框都能直接粘；
  自己写回的内容用命名格式屏蔽，避免粘贴回环。
- 粘贴动作 = 写剪贴板 → 隐藏面板 → 注入 Ctrl+V。清理历史在面板里做；`max_entries`
  超限时旧的先淘汰。

## 3. 计时器（`global.timer.*`）

- 模式：`countup` 正计时 / `countdown` 倒计时（番茄钟已删除，老配置里的残留会被忽略）。
- 倒计时时长 `duration_sec`；横幅锚点 0–6（中央 / 顶部居中 / 底部居中 / 四角），
  贴边锚点才有水平 / 垂直偏移（屏幕百分比）；字号 `font_pt` 决定整体大小。
- 快捷键是一键开关：按开始，再按停止并清零；空串 = 停用。横幅在覆盖层上，受设置页
  「总在最上 / 全屏避让」管辖。

## 4. AI 的任务路线

这三件都没有脚本钩子（没有 `draw` / `run` 可以写）。AI 只能：

1. **改配置**：`sticky_note.*` / `clipboard.*` / `global.timer.*`，见《配置说明》；
   运行中改文件会被内存配置覆盖，先退出程序再改。
2. **解释行为**：例如"便签为什么不保存"、"剪贴板图片存在哪"、"计时器横幅为什么被全屏挡住"。
3. **排错**：快捷键不响应先查功能开关与是否为空；剪贴板没记录先查功能是否启用、
   是否被安全软件拦了剪贴板监听。

## 5. 边界与常见错

| 症状 | 先查 |
|---|---|
| 便签关掉后文字没了 | 便签本来就不持久化 |
| 剪贴板历史重启后变空 | `temp/clipboard/` 被工作文件夹清理或用面板"清空"过 |
| 复制的图片在面板里是空缩略图 | 原件在 `temp/clipboard/images/` 被删了；条目只剩元数据 |
| 计时器横幅被游戏盖住 | 设置页「全屏避让」是否勾选；勾上会整体让位 |
| 倒计时秒数对不上 | 模式/时长改完是否真的落盘；快捷键是否绑在另一套配置上 |
