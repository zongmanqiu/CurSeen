CurSeen 操作手册

这份手册讲怎么用：默认快捷键、每个功能的用法、产物放在哪，以及怎么把程序接到 AI 上让它帮你写脚本。
适用版本：随本手册同包的 CurSeen（AGPL-3.0）。不同版本若调整了操作，以程序实际行为为准。

一、快速开始

  • CurSeen 是便携程序：解压即用，配置、日志、缓存、临时产物都在程序目录里， 不写 %APPDATA%；卸载 = 删除整个目录。
  • 默认按 Ctrl + Shift + D 呼出 / 收起控制面板。按了没反应， 多半是这把键被改过或与别的软件冲突，去「设置 → 快捷键」重绑一把。
  • 大多数功能出厂是关着的：在对应卡片标题栏左侧的开关打开它。
  • 各功能的快捷键出厂大多留空（空框 = 停用且看得见），需要什么自己绑一把， 不会预占你的全局键位。
  • 遇到固定键（界面里没写、也不能改的那些），都写在对应功能章节里。

三、鼠标特效

鼠标页四张卡，每张卡标题栏的开关就是该功能的唯一开关。

拖尾

  • 在「拖尾」卡选特效（下拉），下面的参数行随特效变化；改完即时生效。
  • 颜色、密度、淡出速度、粒子大小等都由特效自己声明；不同特效的可调项不一样。
  • 拖尾是连续动画：指针移动时持续绘制，静止后自动停笔；停住不动不占 CPU。

悬浮标

  • 「类型」下拉选样式（实心圆 / 圆环 / 图片 / 激光笔 / 聚光灯 / 标尺 / 眼睛跟随 / 弹簧挂件…）。
  • 选「图片」时，在「图片」行点「浏览…」导入 PNG / GIF；素材会复制进 assets/lua/HoverDot/，换电脑或搬目录不会失效。
  • 悬浮标是指针的常驻挂件：指针不动就不出帧；淡出、弹簧回摆这类动画会自己续帧，收敛后回到静止零功耗。

点击效果

  • 父卡开关控制整个功能；下面按鼠标键（左 / 右 / 中 / X1 / X2）各一张子卡。
  • 每个键的下拉第一项是「关闭」——这一键停用；选具体效果后，下面的参数只影响该键。
  • 点击效果是一次性动画：触发一次、自己淡出消失，不会常驻。

点击声音

  • 按鼠标键分别选「关闭 / 音频文件」；音量单独可调。
  • 声音素材默认取自程序目录的 assets/Sounds/；丢一个音频文件进去就能在下拉里选到。
  • 想同时有「点击效果 + 点击声音」，两张卡都打开即可，它们互不影响。

四、键盘与虚拟键盘

击键回显

  • 标题栏下拉选显示哪些键：全部 / 排除鼠标 / 组合键 + 功能键 / 只看组合键。
  • 「位置」选四个角落之一并微调偏移；「显示」调宽度、不透明度、停留时长、字号、合并间隔；
    「颜色」调背景、普通键、功能键、符号键四色。
  • 想改按键在弹窗里的文字：编辑 assets/KeyDisplay/keynames.ini， 保存后按一次键即生效，不用重启（格式与键名清单在文件头）。

击键音效

  • 「脚本」下拉选音效方案（出厂有统一音效 / 分类音效两种），音量单独可调。
  • 音效文件同样可以放到 assets/Sounds/ 后在下拉里选。

虚拟键盘

  • 标题栏的「方案」下拉选键盘布局；「位置 / 窗口行为 / 显示 / 颜色」四张子卡调位置、
    鼠标穿透、键帽尺寸、圆角、不透明度、高亮保持、字号与各命名样式的颜色。
  • 方案来自 assets/VirtualKeyboards/*.json：一个文件一套方案，文件名即方案名。
    换方案或改面板参数后，键盘会按新尺寸重排。
  • 勾选「鼠标穿透」后，键盘不拦鼠标，点击会落到下面的窗口——想正常操作就取消它。

直播捕获

在「虚拟键盘 → 直播捕获 → 画面来源」三选一：

来源怎么用注意
桌面 出厂选择；直播软件里加「显示器捕获」即可 不需要额外设置
独立窗口 多出一扇 CurSeen 虚拟键盘 窗口，直播软件里加「窗口捕获」 窗口可拖、可关、可最小化；关窗 = 取消这一选择；最小化时抓不到；需要加色键抠底
浏览器源 点「复制地址」，粘到 OBS / 直播姬的「浏览器」来源 地址必须带完整 http://；只适用于 OBS 家族；画面自带透明通道，不用色键
  • 窗口嫌糊就调「窗口缩放」（0.5–3×）：它是重新矢量渲染，不是把像素拉大； 在直播软件里把来源拉大只会更糊。
  • 浏览器源照「来源尺寸」填宽高，键盘正好铺满，不会留黑边。
  • 抠图底色与键帽撞色时，色键会把键帽一起抠穿；撞了就换一色。

五、屏幕

屏幕标注

  • 父卡「屏幕标注」的开关是唯一开关；「画笔」调三支笔的颜色 / 粗细 / 线型； 「快捷键」可绑定各工具与屏幕标注 / 白板的启停键。
  • 导出的是带标注的 PNG，落在 temp/annotation/；需要留存就另存到别处。
  • 固定编辑键：Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做、 Backspace 撤销、Delete 清空画布、Esc 退出标注（保留内容）。
    截图编辑态下 Esc = 放弃本次编辑，完成只走工具栏「保存」。

放大镜

  • 画中画：调面板宽高、倍率、锚点（含跟随鼠标）与描边色；启停键可绑。
  • 全屏放大：倍率 1–5；Esc 永远能退出（不依赖快捷键是否绑定）。
  • 固定键：Ctrl + Win + 滚轮 调倍率（上滚放大 / 下滚缩小，步进 ±1）， 仅在放大镜在屏上时拦截滚轮。

截图与贴图

  • 四把键（都可绑）：截图（区域 → 剪贴板 + 留档）、截图后贴图（区域 → 剪贴板 + 钉到桌面）、
    贴图（从剪贴板历史取图文钉到桌面）、长截图（开始 / 结束一键开关）。
  • 截图默认不弹保存框：临时留档在 temp/screenshot/；要留的文件用贴图右键「另存为」。
  • 贴图素材来自剪贴板历史：图片按原件、纯文字栅格化成图、文件条目不参与；连按贴图键沿历史往前翻。
  • 固定键：Ctrl+S 把选中的贴图另存为 PNG（没有选中时原样透传，不会误吞前台程序的保存）； Esc 关闭选中的贴图；截图时按住 Ctrl 进入编辑态。
  • 贴图选中后可拖动移动、滚轮缩放（若开启对应开关）；被脚本换过图时，右键有「恢复原图」。

GIF 录制

  • 「录制」是一键开关：按下开始框选，再按一次停止落盘；「裁剪」键可单独打开裁剪窗。
  • 可调帧率与「录制鼠标」；选框即输出尺寸，循环恒定开启。
  • 产物在 temp/gif/；裁剪窗「打开…」默认也从这个目录开始。

视频录制

  • 「录屏」是一键开关：按下开始、再按一次停止；区域与裁剪各有自己的键。
  • 画面：帧率 / 分辨率 / 码率 / 硬件加速 / 录制鼠标；声音：系统声音、麦克风（三态来源：关闭 / 默认 / 指定设备）+ 降噪。
  • 没有暂停：要分段就停掉再开。产物在 temp/record/。
  • 录完没声音，先查两路音频来源是否指向「关闭」。

六、工具

便签

  • 快捷键呼出一张新便签，可同时开多张；可拖动、置顶锁定、收起编辑区。
  • 可调背景色 / 文字色 / 编辑区色、不透明度、字号。
  • 便签内容不落盘：关掉窗口或重启程序就没了；长期保存请用别的工具。
  • 固定键：Esc / Enter 关闭「透明度」小弹窗。

剪贴板历史

  • 快捷键呼出面板；后台自动记录复制内容，支持类型过滤、搜索、收藏、悬停预览、点击粘贴。
  • 条目优先级：文件 > 图片 > 文本。图片会落盘到 temp/clipboard/，历史记录重启后仍在。
  • 历史条数上限在面板里设；超限时旧的先淘汰。
  • 面板导航键：↑ / ↓ 移动选中、Enter 粘贴、Esc 收起。 打开面板本身的快捷键在「设置 → 快捷键」里绑。

计时器

  • 模式：正计时 / 倒计时；倒计时可设时长。
  • 横幅位置可选中央、顶部/底部居中或四角；贴边时才有水平 / 垂直偏移；字号决定整体大小。
  • 快捷键是一键开关：按开始，再按停止并清零。

七、脚本与资源包

  • 脚本页第一张卡是在线资源下载：搜索、下载、升级、卸载官方脚本包 （鼠标特效、AI 写脚本、图片体检、OCR、条码等）。下载源在「设置 → 高级」。
  • 装好的脚本在脚本页各有一张卡片：标题栏的开关决定它是否运行 / 是否出现在菜单， 正文是脚本自己声明的参数。
  • 脚本也可以直接放进 assets/lua/ 的对应目录。五个挂载目录的脚本文件改完都会热重载 （击键音效在下一次按键生效）；启用开关、参数这类配置仍要重启一次程序才完全生效。
  • 脚本的结果窗口可以直接选中复制。
  • 想自己写脚本：交给 AI 就行，见下一节。

八、设置

  • 快捷键：所有可配置热键集中在这里。点一行进入捕获态，按下想要的键即完成绑定； 清空即停用。面板、截图、录屏、放大镜、便签、剪贴板都在这里改。
  • 功能开关：各页面卡片标题栏的开关在这里有一份镜像，勾一处两边同步。
  • 高级：下载源、覆盖层置顶 / 全屏避让、工作文件夹自动清理、管理员启动等。
  • 帮助：打开本手册。

九、★ 让 AI 帮你写脚本

你不需要配置 MCP，也不用记任何命令。把下面这段话发给一个能读写本机文件、 能运行命令的 AI（Qoder、WorkBuddy、Claude Code、Cursor 等），它会先读随包文档， 自己把 CurSeen 接到 MCP，再按你的描述把脚本写出来、跑通、启用。

可直接复制发给 AI 的话 
我有一个 CurSeen 项目，程序在 <换成程序所在文件夹，例如 D:\Apps\CurSeen>。

请先做两件事：
1. 打开程序目录下的 assets/docs 文件夹，读 README.md、接入指南.md、MCP说明.md。
   接入指南里有把 CurSeen 接到 MCP 客户端的完整步骤，请照着帮我接好；需要我重启客户端、
   点确认或提供路径的地方，直接告诉我。
2. 接好之后，先告诉我你看到了哪些工具、脚本准备放在哪个目录、打算怎么做，等我确认再动手。

然后实现我要的效果：<用大白话描述，越具体越好，例如「鼠标移动时留一条彩虹拖尾，停住后 0.5 秒内淡出」>。

实现时遵守：先 write_script，再 lua_check（warnings 要为空），再 lua_trace，直到 verdict=pass；
judged=false 的明确告诉我需要真机验收；最后 set_active 启用，并告诉我用户在哪里能看到。
不要覆盖已有脚本；不要改 assets/ 以外的文件；不要自己发明不存在的接口。
红色 <...> 是你要改的两处：程序文件夹、效果描述，其余原样发给 AI。 如果 MCP 没接上，把 AI 报的错原样发回给它，它会按接入指南排查；你不需要自己看配置。

十、常见问题

按快捷键没反应？

先看对应功能卡片的开关是否打开、快捷键是否为空；再确认是否与别的软件冲突。 绑定 / 修改都在「设置 → 快捷键」。

找不到截图 / 录屏文件？

它们默认落在 temp 下按功能分的目录（截图 / Gif / record / annotation）， 截图本身还同时进了剪贴板。要留存就用「另存为」。

特效 / 键盘不出现？

看该功能的开关与方案是否选中；直播捕获还要看直播软件里加的是不是对应的来源类型。

关闭面板后特效还在吗？

在。控制面板只是设置界面，功能按自己的开关运行；要停就关对应功能卡片的开关。

全屏游戏里看不见特效？

看「设置 → 高级 → 覆盖层」：「总在最上」默认开；勾了「全屏避让」时前台全屏应用会让位。

能离线用吗？

可以。程序本身不联网；只有下载脚本包、检查更新时才需要网络。

卸载要删什么？

删除整个程序目录即可。配置、日志、缓存、临时产物都在里面，不写注册表和 AppData。
