# 鼠标特效（拖尾 / 悬浮标 / 点击效果 / 点击声音）

这份文档只讲**鼠标页那四张卡**：它们各自显示什么、脚本挂在哪、AI 改这些功能时该走哪条路。
配置键的完整定义与案例统一在 [`配置说明.md`](配置说明.md)，这里不重复键表。

## 1. 这个主题管什么

鼠标页从上到下四张功能卡（每张卡的标题栏开关就是该功能的唯一开关）：

| 卡 | 在屏幕上的表现 | 触发模型 |
|---|---|---|
| 拖尾 | 指针移动时在身后留下轨迹 | 连续动画：跟随移动，静止可停 |
| 悬浮标 | 指针周围的常驻挂件（圆、环、图片、眼睛…） | 静态跟随：指针不动就不出帧 |
| 点击效果 | 按下鼠标键时的一次性动画（波纹、喷泉、星芒…） | 一次触发，**必须自己停笔** |
| 点击声音 | 按下鼠标键时播放一段音频 | 按键触发一次 |

出厂配置里所有功能默认关闭；四张卡的开关互不依赖。

## 2. 怎么配（键名 → 配置说明）

- 拖尾：`trail.trail_enabled`、`trail.trail_effect`、`trail.trail_settings.*`（淡出、密度、
  不透明度、生成间隔、粒子大小、颜色模式 / 固定色）。
- 悬浮标：`trail.hover_enabled`、`trail.hover_type`、`trail.hover_params.<类型>.<参数>`、
  `trail.hover_image`（PNG / GIF 文件名，素材在本程序目录的 `assets/lua/HoverDot/`）。
- 点击效果：`trail.ripple_enabled` + `trail.ripple_bindings.<left|right|middle|x1|x2>`
  （`enabled` / `script` / `size` / `duration` / `color` / `script_params`）。
- 点击声音：`trail.sound_enabled` + `trail.sound_bindings.<键>`（`enabled` / `file` / `volume`）。

`ripple_left_enabled` / `sound_left_file` 这类扁平旧键仍在（老配置兼容），**新写入只用
`ripple_bindings` / `sound_bindings`**。逐键手改的写法与案例见《配置说明》§B / §C。

颜色串只有 `#RRGGBB` 与 `#RRGGBBAA` 两种，**没有** `#AARRGGBB`。

## 3. 脚本接口（三类特效脚本）

挂载点由**目录**决定，不由脚本自报：

| 目录 | 宿主 | 回调 | 契约要点 |
|---|---|---|---|
| `assets/lua/MouseTrail/` | `trail` | `draw` / `step` / `on_move` / `on_press` / `on_mouse_up` / `on_wheel` | 移动期持续产出；静止允许不再要帧 |
| `assets/lua/HoverDot/` | `hover` | `draw` / `init` / `on_move` / `step` / `on_press` | **不转发 `on_mouse_up`**；静止后动画未收敛必须 `return 16` 续帧 |
| `assets/lua/ClickFx/` | `clickfx` | `draw` / `step` / `on_press` / `on_click` / `on_mouse_up` | 出生补发一次 `on_move`；寿命到了必须停止产出，否则实例永不释放 |

共同规则（`lua_trace` 会自动判，不过就是不过）：

1. `draw` 第 0 帧必须产出指令——宿主按"这一帧画不画"判活。
2. 任何时间驱动的动画（淡出、弹簧回摆、平滑追赶）都要在 `draw` 返回正数毫秒续帧；
   收敛后必须不再返回，否则静止态永久烧 CPU。
3. 坐标是**虚拟桌面物理像素**（副屏在主屏左侧时为负），不是窗口逻辑坐标。
4. 脚本要隐藏系统箭头时声明顶层 `hide_cursor = true`（I 形 / 手形指针保留）。
5. 三类目录**都热重载**：改完脚本文件后实例会重建，不需要重开面板。

悬浮标的额外约定（续帧阈值、图片坐标系）见 `../lua/HoverDot/README.md`；接口签名见
`../lua/API.md` §8 / §10。

## 4. AI 的任务路线

**写一个新的拖尾 / 悬浮标 / 点击效果**

1. `list_scripts` 看同类脚本的文件名与 id，别自己发明目录。
2. `read_doc` 读 [`Lua开发指南.md`](Lua开发指南.md) 与目标目录的 `README.md`（悬浮标有）。
3. `write_script`（MCP）或直接写 `assets/lua/<目录>/<名字>.lua`（有文件权限）。
4. `lua_check` → `lua_trace`（`mode` 一般不用填，按目录推断）→ `verdict=pass`。
5. `set_active` 启用并写参数；脚本文件改动已热重载，配置项要重启一次程序才完全生效。

**改一个已启用特效的参数**：优先 `set_active(script, params={...})`——它替调用方处理
悬浮标裸 stem、拖尾扁平命名空间、点击落 `ripple_bindings.<键>` 这三种历史差异。

**换悬浮标图片**：图片必须复制进 `assets/lua/HoverDot/`，配置只记文件名（P12 迁移时
素材与配置一起搬）。MCP 没有写图片的通道，这一步要用户在面板里导入。

## 5. 边界与常见错

| 症状 | 原因 |
|---|---|
| 下拉里找不到刚写的脚本 | 放错挂载目录；或 `role` / `requires` 把它挡了 |
| 参数拖了没反应 | 参数只在 `schema()` 声明、脚本里没读；`lua_check` 会报 warning |
| 改了 schema 默认值，画面没变 | 脚本里 `params.x or 默认` 的兜底值与 schema 不一致（离屏不吃默认值） |
| 指针停住后特效冻在半空 | 时间驱动动画没续帧 |
| 点击效果永不消失 | `draw` 没在寿命结束后停止产出 |
| 改完脚本没生效 | 文件改动会热重载；查宿主是否在跑（`host_status`），再看脚本是否加载失败 |

不要重命名出厂脚本：用户配置里的 id（文件名 / 裸 stem）会全部失效。
