CurSeen 隐藏快捷键与技巧手册

本手册收录界面里没有写出来的快捷键与操作。为了让控制面板保持干净，
这些键不占用任何 UI 空间——它们是固定的、不可修改的（与「设置」页「快捷键」卡里
那些可以在面板里查看、重绑的全局热键不同）。

适用版本：随本手册同包的 CurSeen（AGPL-3.0）。不同版本若调整了快捷键，以程序实际行为为准。

一、贴图（截图 / 粘贴到桌面的图像）

贴图 = 截图后钉在桌面的图，或把剪贴板里的图片「贴图」到桌面。

快捷键 作用 说明
Ctrl + S 把当前选中的那张贴图另存为 PNG 存的是当前画面（脚本换图后也存换后的结果，不是出厂原图）；仅当存在「被选中的贴图」时生效，没有选中则忽略，按键照常透传。
Esc 关闭当前选中的贴图 仅当处于「贴图选中」状态。
截图时按住 Ctrl 进入截图编辑态 在按截图键或拖选区的同时按住 Ctrl：可框选调整、可标注；确认后是否贴图取决于用的是哪把键。这是从基础截图键派生出来的 Ctrl 变体。

提示：贴图选中后，用鼠标拖拽可移动，滚轮可缩放（若已开启对应开关）。
如果贴图被脚本换过图（ext:set_image），右键会出现「恢复原图」——换回钉进来那一刻的画面。

二、屏幕标注（画笔 / 白板）

屏幕标注模块内部的工具切换键（画笔 1–3、橡皮、直线、箭头、矩形、椭圆、文字、马赛克、
开/关屏幕标注、开/关白板）是配置驱动的，在「屏幕」页的对应卡片里可见、可改，这里不重复。
下面这些是固定、不写在 UI 里的编辑键：

快捷键 作用
Ctrl + Z 撤销一步
Ctrl + Shift + Z 重做
Ctrl + Y 重做（与上等价）
Backspace 撤销一步（与 Ctrl+Z 相同）
Delete 清空整块画布
Esc 退出 / 收掉标注（并保留标注内容）
Esc（截图编辑态） 放弃本次截图编辑（仅当文字输入窗未打开时）；编辑态下 Enter 被设为「无反应」，完成只走工具栏「保存」，放弃走 Esc

这些固定键仅在「画笔」开关开启、且非挂起态下生效。

三、放大镜

快捷键 作用 说明
Ctrl + Win + 滚轮 调整倍率（上滚放大 / 下滚缩小，步进 ±1，范围 1–5） 内置手势，刻意避开 Ctrl+滚轮、Ctrl+Alt+滚轮 等常见绑定；仅在放大镜在屏上（武装态）才拦截滚轮，否则滚轮完全不受干预。
Esc（全屏放大镜） 退出全屏放大镜 全屏窗盖住一切时的逃生键，裸 Esc 不带修饰键。

四、剪贴板历史面板

打开剪贴板历史面板后，面板获得键盘焦点时的导航键（这些在任何 UI 文本里都没有提示）：

快捷键 作用
↑ / ↓ 上移 / 下移选中项
Enter 粘贴选中项
Esc 收起面板

打开面板本身的快捷键是配置驱动的（「工具」页里的「剪贴板历史」热键，出厂留空）。

五、便签

快捷键 作用
Esc / Enter 关闭便签的「透明度」小弹窗

呼出便签本身的快捷键是配置驱动的（「工具」页里的「便签」热键，出厂留空）。

六、脚本文本窗与 AI 对话窗

快捷键 作用
Ctrl + A 文本窗全选
Ctrl + C 复制选中文本
Esc 关闭文本窗 / AI 对话窗
Ctrl + Enter AI 对话窗发送消息（普通 Enter 只换行）

文本窗是脚本的结果 / 输入窗（「图片体检」「OCR 文字识别」等官方脚本都会用）：
内容可直接选中复制，也可以改完再点「复制」，交出去的是当前内容。
AI 对话窗来自官方「AI 写脚本」包；会话保存在本机，关窗/重启后自动恢复，点「清除」才清空。

七、与「可配置热键」的区别

上面所有键都是固定、不可修改的。与之相对，「设置」页「快捷键」卡里列出的那些是
可配置的全局热键（例如呼出/收起控制面板、截图、录屏、放大镜、便签、剪贴板历史等），
它们的出厂默认大多留空（= 停用），需要你在面板里自行绑定后才生效，并且可以随时重绑。

如果你想要的是「怎么改那些能改的键」，请打开 控制面板 → 设置 → 快捷键，
点击任意一行进入捕获态、按下想要的键即可。

八、小提示

  • 所有隐藏键都不依赖控制面板是否打开（除了剪贴板历史面板的 ↑↓/Enter/Esc 需要面板开着）。
  • 若某个隐藏键「没反应」，先确认对应功能开关已开启（如「画笔」「放大镜」）。
  • 贴图 Ctrl+S 只在有贴图被选中时拦截按键；没有选中贴图时，Ctrl+S 会原样透传，
    不会误吞前台程序的保存。
